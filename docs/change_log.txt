项目修改日志
============

[2026-09-09] 第一阶段：理想双说话人 TSE 仿真数据

修改脚本/文件：
1. dasr/data/generate_tse_mixtures.py
   原因：新增独立的双说话人 FOA 仿真管线，保存 mixture、target clean、
   interferer、enrollment 和目标方位标签，为 TSE、ASR、speaker embedding、
   VAD 及 DOA 联合训练提供完整监督。保留原 generate_synthetic_foa.py，
   避免破坏现有单说话人定向 ASR 数据管线。

2. docs/tse_data_contract.txt
   原因：固定第一阶段理想仿真数据的字段、目录、空间音频约定和监督关系，
   为后续性别识别、情绪识别等任务扩展统一数据接口。

3. tests/test_tse_data.py
   原因：验证说话人 ID 推断、左右方位映射、FOA 混合可加性、enrollment 与
   target 身份一致性以及 target/interferer 身份隔离。

4. docs/change_log.txt
   原因：按项目要求记录本次修改的文件和修改原因；后续每次代码或配置修改
   都必须在本文件追加独立条目。

[2026-09-09] 第二阶段：实现 TSE Dataset 与 batch 接口

修改脚本/文件：
1. dasr/data/tse_dataset.py
   原因：将 TSE manifest 解析为 mixture、target、interferer、enrollment 四路
   音频，并提供长度、粗粒度 VAD、左右/DOA、转录和说话人 ID，供后续联合模型使用。

2. docs/tse_dataset_interface.txt
   原因：固定 Dataset/Collator 的张量形状和字段契约，避免后续模型分支各自解释数据。

3. tests/test_tse_data.py
   原因：验证 TSE Dataset 的相对路径解析、音频校验和 target 元数据读取。

[2026-09-09] 第三阶段：目标条件空间编码和多任务头

修改脚本/文件：
1. dasr/model/config.py 和 conf/dasr_defaults.yaml
   原因：增加 enrollment encoder、target fusion 和 TSE head 的结构配置，保持
   Qwen3 解码器配置不变。

2. dasr/model/enrollment_encoder.py
   原因：将目标说话人 enrollment 编码为归一化 speaker embedding，作为目标选择条件。

3. dasr/model/target_fusion.py
   原因：使用 enrollment cross-attention、token-speaker 相似度门控和 FiLM 调制，
   将目标身份注入 FOA 空间 token，形成 target-conditioned 表征。

4. dasr/model/target_conditioned_encoder.py
   原因：组合空间编码器、enrollment encoder 和 target fusion，提供后续训练统一接口。

5. dasr/model/tse_heads.py 和 dasr/model/tse_losses.py
   原因：新增 complex mask、VAD、DOA、speaker embedding、左右方向输出及 SI-SDR、
   speaker consistency、VAD、DOA、side 联合损失。

6. dasr/model/__init__.py
   原因：导出第三阶段新增模块，方便训练入口复用。

7. tests/test_tse_model.py
   原因：验证目标条件模块和多任务头的张量形状及损失数值稳定性；无 torch 环境时自动跳过。

[2026-09-09] 第四阶段：共享 target token 的联合 TSE-ASR 模型

修改脚本/文件：
1. dasr/model/joint_model.py
   原因：将 target-conditioned token 同时连接 Projector/Qwen 接口和 TSE、VAD、
   DOA、speaker 头，避免把 waveform 提取结果硬级联到 ASR。

2. dasr/model/tse_losses.py
   原因：增加 complex mask 到目标波形的可微重建和角度目标转换，支持共享表示的联合 loss。

3. dasr/model/__init__.py 和 tests/test_tse_model.py
   原因：导出联合模型并增加 mask 重建输出形状与数值稳定性测试。

[2026-09-09] 第五阶段：引入 speaker teacher 两阶段蒸馏接口

修改脚本/文件：
1. dasr/model/config.py 和 conf/dasr_defaults.yaml
   原因：增加 teacher embedding 维度配置，为冻结的 WavLM/ECAPA/WeSpeaker
   speaker teacher 提供可配置接口。

2. dasr/data/tse_dataset.py 和 docs/tse_dataset_interface.txt
   原因：允许 manifest 携带可选 teacher_embedding，并在 collator 中组成 batch，
   支持先训练目标身份表示、再训练 TSE/ASR 的两阶段策略。

3. dasr/model/tse_losses.py 和 dasr/model/joint_model.py
   原因：增加 enrollment/target speaker embedding 的 cosine distillation loss，
   teacher 不反向传播；对应近期 TSE 工作中冻结 speaker teacher 和 cue pretraining 的做法。

4. tests/test_tse_data.py
   原因：验证 teacher embedding 字段可随 manifest 读取，且不影响原有样本契约。
