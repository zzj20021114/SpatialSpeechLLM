# 组会周报（2026-08-26）

## 一、本周工作概述

本周围绕课题目标——**基于 Qwen3 的定向多任务语音理解大模型**，完成了从方案设计、
核心代码实现到训练数据落地的全链路准备。课题融合两个上游工作：

### 5. 技术问题与解决
| 问题 | 解决方案 |
|---|---|
| 镜像源 `pkgs/r` 失效 | 修正 `~/.condarc` 频道配置 |
| `/public` 外部目录被工具权限拦截 | 改用 Python `shutil` 批量复制 |
| 14 万小文件 NFS 复制极慢 | 改为复制 400 个按说话人 tar.gz（快约 10 倍），本地解压 |
| 串行合成长时运行被工具超时终止 | `setsid` 独立会话 + 多进程 + 断点续跑 + 每索引可复现随机种子 |
| 噪声合成 bug（`random.Random` 无 `.normal`） | 改用独立 `numpy` RNG |
| Qwen3-Omni 镜像下载 401（Xet 存储需认证） | 禁用 Xet（`HF_HUB_DISABLE_XET=1`），回退普通 LFS 下载 |
| FOA 输出体积膨胀（float32 4 通道 = 8 倍原始） | 改 PCM_16（4 倍），可再减 |

## 四、下一步计划

1. **本周内**：完成全量 FOA 合成与 QA 构建；完成 Qwen3-Omni 权重下载。
2. **冒烟训练**（GPU5）：用少量样本跑通 S1（投影器对齐）→ S2（LLM LoRA + 投影器，
   ASR+X 联合）全链路，验证 loss 收敛与显存占用。
3. **正式训练**：全量数据 S2 训练 → S3（解冻空间编码器微调），评估左右准确率 + CER。
4. **基准与消融**：与"仅单声道 ASR""无空间分支"等基线对比，量化空间分支收益。
5. **中期**：扩展到多说话人、degree 方位回归（代码已预留），接入更多空间音频评测。

## 五、风险与依赖

- **基座模型下载**：Qwen3-Omni-30B-A3B 权重约 60GB，依赖网络带宽；如镜像受限，
  可临时用本地缓存的 Qwen2.5-Omni-7B 跑通管线（架构兼容）。
- **显存**：30B MoE + LoRA + bf16 在 32GB 卡上可行（需梯度检查点/小 batch），
  单卡冒烟够用，正式训练建议 2–4 卡。
- **数据规模**：AISHELL-1 为干净朗读，与真实场景存在分布差异；二期引入
  噪声/混响增强与真实多通道数据。
